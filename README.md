## ✦ Sobre a atividade

Este repositório foi desenvolvido como parte de uma **atividade avaliativa da disciplina de Sistemas Web II (SW-II)**.

O projeto consiste no desenvolvimento de uma aplicação web, realizada de forma **incremental e dividida em 4 etapas**. Cada etapa acrescenta novas funcionalidades ao sistema e deve ser entregue conforme as orientações da disciplina.

Ao final das quatro etapas, o projeto deverá apresentar uma aplicação funcional, integrando **Front End, Back End, API e Banco de Dados**.

---

# ◆ Etapas da atividade

O desenvolvimento do projeto será realizado em **4 etapas**.

### 01 · Fundação

Nesta primeira etapa será criada a estrutura inicial do projeto.

Serão trabalhados:

* Configuração do ambiente;
* Organização inicial dos arquivos;
* Configuração do Back End;
* Criação e conexão com o Banco de Dados;
* Primeiras rotas da aplicação.

---

### 02 · Modelo e consultas

Nesta etapa serão desenvolvidas as primeiras funcionalidades do sistema.

Serão trabalhados:

* Criação dos modelos;
* Configuração das tabelas do banco;
* Criação dos schemas;
* Conexão com o banco de dados;
* Cadastro de informações;
* Consulta e listagem de dados.

---

### 03 · CRUD completo

Nesta etapa o sistema será ampliado para possuir as principais operações de um CRUD:

* **Create** — Criar;
* **Read** — Consultar;
* **Update** — Atualizar;
* **Delete** — Excluir.

Também serão realizados testes e tratamento de possíveis erros da aplicação.

---

### 04 · Front End

Na última etapa será desenvolvida a interface do sistema.

O Front End será responsável por consumir a API e permitir que o usuário interaja com as funcionalidades desenvolvidas nas etapas anteriores.

Serão trabalhados:

* Interface Web;
* Formulários;
* Exibição dos dados;
* Edição de informações;
* Exclusão de informações;
* Integração com a API.

---
